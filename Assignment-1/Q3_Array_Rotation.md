Q3. Rotate a 1-D Array by K Positions

Logic:

1. Start.
2. Input the number of elements, n.
3. Input the elements of the array.
4. Input the value of K.
5. For Left Rotation:
   a. Repeat the rotation K times.
   b. Store the first element in a temporary variable.
   c. Shift all remaining elements one position to the left.
   d. Place the temporary element at the last position.
6. For Right Rotation:
   a. Repeat the rotation K times.
   b. Store the last element in a temporary variable.
   c. Shift all elements one position to the right.
   d. Place the temporary element at the first position.
7. Display the left rotated array and right rotated array.
8. Stop.
