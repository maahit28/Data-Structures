(a). Reverse the Elements of an Array

Logic:
1. Start.
2. Input the number of elements, n.
3. Input the elements of the array.
4. Set two positions:
   start = 0
   end = n - 1
5. Repeat while start < end:
   a. Swap the elements at start and end.
   b. Increment start by 1.
   c. Decrement end by 1.
6. Display the reversed array.
7. Stop.

    (b). Matrix Multiplication

Logic:

1. Start.
2. Input the number of rows and columns of the first matrix.
3. Input the number of rows and columns of the second matrix.
4. Check whether the number of columns of the first matrix
   is equal to the number of rows of the second matrix.
5. If they are not equal, matrix multiplication is not possible.
6. If they are equal:
   a. Multiply the corresponding elements of each row of the
      first matrix with each column of the second matrix.
   b. Add the products.
   c. Store the result in the corresponding position of
      the result matrix.
7. Display the result matrix.
8. Stop.


(c). Transpose of a Matrix

Logic:

1. Start.
2. Input the number of rows and columns of the matrix.
3. Input the matrix elements.
4. Interchange the rows and columns of the matrix.
5. For each element:
   a. Store matrix[i][j] in transpose[j][i].
6. Display the transpose matrix.
7. Stop.
